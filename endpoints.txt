# check validates this file BOTH ways:
#   * every line must exist in the pinned spec (no removed, renamed or typo'd
#     operation);
#   * the set must equal the requests the SDK's exported methods actually send.
#     The test calls every method against a recording server, so there is no
#     hand-kept list of what the code calls.
#
# Add a line here whenever you add a method for a spec operation, or the check
# fails. An operation the pinned spec does not define is not wrapped; the one
# route the SDK sends outside the spec is named, with its reason, in offSpec in
# specdrift_test.go. Format:
#   METHOD /path   (path placeholders as the spec spells them, e.g. {market_id})
#
# Paths are the spec's. The SDK sends every route on the /v1 edge mount (see
# network.go), so a line the spec declares only on the /api/v1 dual mount (the
# bridge reads) is sent without that prefix: /v1/bridge/assets.
